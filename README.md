## Overview

Watchtower is an Android application designed to help users document and track security incidents, activities, and observations. The app provides a secure platform for logging incidents with timestamps and maintaining an activity history for personal safety awareness.

## Features

- **Incident Reporting**: Document security incidents with detailed descriptions and automatic timestamps
- **Activity Logging**: Track and view historical activity logs
- **User Authentication**: Secure login system to protect sensitive information
- **Dashboard**: Centralized view of recent activities and incidents
- **Notifications**: Stay informed about important updates and alerts

## Technology Stack

- **Platform**: Android (API 24+)
- **Language**: Kotlin
- **Architecture**: MVVM with Navigation Components
- **UI Framework**: Android Jetpack with View Binding
- **Minimum SDK**: Android 7.0 (API level 24)
- **Target SDK**: API level 36

## Prerequisites

- Android Studio Arctic Fox or newer
- JDK 11 or higher
- Android SDK with API level 24 or higher

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ceakin-cyber/watchtower.git
   ```

2. Open the project in Android Studio

3. Sync the project with Gradle files

4. Build and run the application on your device or emulator

## Usage

1. **Login**: Start by creating an account or logging in with existing credentials
2. **Home**: Navigate through the bottom navigation to access different features
3. **Dashboard**: View overview of recent activities and system status
4. **Incident Reporting**: Document new incidents with detailed information
5. **Activity Log**: Review historical data and incident reports
6. **Notifications**: Receive important alerts and updates
